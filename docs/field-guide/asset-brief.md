# Asset brief: photographs for the Field Guide homepage and Lens

The redesign ships with the site's existing photographs standing in. Matthew replaces stock imagery with custom assets from a brief, so this is that brief. Every slot below is a real picture of ordinary family life: natural light, ordinary rooms, hands and objects and concentration, children and families depicted respectfully, never a smiling-stock pose, never a distressed child used for effect. One light and one grade across the set (untouched colour, no filters), square corners, no text in the image. Deliver JPEG at the sizes given plus a 2x version where noted.

Rules for every slot:
- Real families, with consent on file. Diversity of families as they are, not as a quota.
- The subject in the calm part of the frame, so the crop can breathe at both desktop and phone sizes.
- No brand colours staged into the scene; the palette comes from the room.
- Alt text will describe what is shown, so the picture must be describable in one plain sentence.

Footage: none is used. If an honest short clip exists (a few seconds of a child absorbed in play, no sound), it can replace the mosaic photograph as a muted loop with a poster frame; the build already supports a moving picture there.

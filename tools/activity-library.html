How these are built

Each activity is written fresh for this library and passes an automated check before it can ship. The check screens every activity’s materials and steps against a list of common choking, strangulation, suffocation, and burn hazards for under-3s; asks for a bite-off note wherever a sponge, foam, or a brush reaches a child under 2; requires an arm’s-reach supervision note on anything with water; and holds one non-negotiable rule: the intention line must name a real developmental mechanism from a controlled vocabulary, so “boosts brain development” hand-waving can’t get through.

An automated check is not a safety review, and a word list can’t catch everything, so read each activity’s safety note with your own child in mind. The library favors ordinary moments over projects; the research consistently finds the developmental value lives in the interaction, not the materials.
